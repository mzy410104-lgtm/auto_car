# Pi–STM32 Interface Agreement

This interface agreement is partially completed. C is [mzy410104-lgtm](https://github.com/mzy410104-lgtm), responsible for the STM32 endpoint. The B member is still to be confirmed. Standalone STM32 communication has been implemented and tested with a Windows host through the onboard ST-LINK virtual COM port. This does not establish the Raspberry Pi wiring or the final application protocol.

| Item | Current value / status | Source or responsibility |
|---|---|---|
| Physical connection and interface routing | Verified on 2026-11-02: Raspberry Pi 4 USB 2.0 port connected to NUCLEO-F103RB onboard ST-LINK/V2-1 USB virtual COM port (`ID 0483:374b`), internally routed to STM32 `USART2`. Enumerates on Raspberry Pi as `/dev/ttyACM0` (`/dev/serial/by-id/usb-STMicroelectronics_STM32_STLink_066DFF485753667187154458-if02`). | NUCLEO-F103RB project configuration, 2026-09-22 standalone test, and 2026-11-02 Pi–STM32 test |
| Pins, power, signal levels and common ground | STM32 `USART2` uses `PA2` TX and `PA3` RX routed through the onboard ST-LINK USB bridge (shared USB ground and USB 5V ST-LINK supply). | `firmware/auto_car/auto_car.ioc` and 2026-11-02 Pi–STM32 verification |
| Communication parameters and message format | `115200` bit/s, `8` data bits, no parity and `1` stop bit (`8N1`). Verified ASCII commands on flashed STM32 firmware: `PING\n` -> `PONG\n` (`\r` ignored, mean RTT `1.84 ms` with `STREAM OFF`), `HELP\n`, `STATUS\n` (`STATUS ARMED=0 ESC_US=1500 SERVO_US=1500 STREAM=0 TIMEOUT_MS=3000`), `STREAM ON|OFF\n`, `STOP\n`, `CENTER\n`, `ARM\n`, `ESC <1300..1700>\n`, `SERVO <1000..2000>\n`. Unrecognized lines return `ERR UNKNOWN; SEND HELP\r\n`. | Standalone protocol test (2026-09-22) and Pi–STM32 test (`onboard/stm32_comm_test.py`, 2026-11-02) |
| Units and direction conventions for target speed and steering | Bench PWM command units on flashed STM32: microseconds (`ESC 1300..1700`, max `20 us` step; `SERVO 1000..2000`, max `5 us` step; neutral/stop = `1500 us`). High-level SI navigation units remain to be agreed by A/B/C. | Joint control/navigation agreement |
| Stop, timeout, error and recovery behavior | `STOP` and `CENTER` immediately set `ESC_US=1500`, `SERVO_US=1500`, and `ARMED=0` (always accepted). Command timeout returns outputs to `1500 us` after `3000 ms`. | Flashed STM32 firmware verified on 2026-11-02 |
| Speed, orientation, distance and status feedback | With `STREAM ON`, STM32 outputs `BNO055` Euler angles (`H_cdeg=<heading> R_cdeg=<roll> P_cdeg=<pitch>`) every `200 ms` and calibration/diagnostics (`CAL SYS=... GYR=... ACC=... MAG=...`) every `1000 ms`. Wheel-speed encoder and SHARP ADC feedback remain to be integrated. | `firmware/auto_car/Core/Src/main.c` and 2026-11-02 Pi–STM32 test |
| Corresponding firmware/host versions and test records | STM32 interrupt-reception firmware: `3f10c88` (plus bench command parser on board). Standalone evidence: `tests/records/2026-09-22_stm32_usart2_interrupt.md` and `tests/records/2026-09-22_stm32_ping_pong_protocol.md`. Pi–STM32 integration script: `onboard/stm32_comm_test.py` and evidence: `tests/records/2026-11-02_pi_stm32_usart2_comm.md`. | Repository commits and actual integration records from both sides |
